# JavaScript Basics Flash Cards

An interactive flip-card quiz with 20 cards covering JavaScript fundamentals: variables, data types, operators, control flow, functions, arrays, and objects.

## Features
- Click or press Space to flip a card
- Mark cards as "Got it" or "Review again" (arrow keys work too)
- Progress saves in your browser with localStorage
- Shuffle, study missed cards only, or reset progress

## How to use
Open `index.html` in any browser, or view it live with GitHub Pages.

## Built with
HTML, CSS, and plain JavaScript. No frameworks. Created with AI assistance as a study project.
